🎓 오늘 발견한 것

a > 0 이면 그래프는 오른쪽으로 갈수록 올라가는 직선, a < 0 이면 내려가는 직선 이에요.
b > 0 이면 그래프는 y축의 양의 부분에서, b < 0 이면 y축의 음의 부분에서 만나요.
